
# Propuesta individual de mejora del dashboard

## 1. ¿Qué cambiaría o agregaría?

Mi propuesta es agregar una sección de alertas para identificar los segmentos de vuelos con mayor tasa de No-Show.

Actualmente, el dashboard permite consultar indicadores y gráficas relacionados con las ausencias de pasajeros. Considero que sería útil complementar esta información con alertas visuales que ayuden a identificar rápidamente los segmentos que requieren mayor atención.

## 2. ¿Para quién sirve y qué decisión facilita?

Esta mejora estaría dirigida al personal encargado de analizar los vuelos y las ausencias de pasajeros.

Las alertas facilitarían la identificación de países, rutas o tipos de vuelo con mayor incidencia de No-Show, permitiendo priorizar el análisis y evaluar posibles estrategias para reducir las pérdidas económicas.

## 3. ¿Qué habría que hacer para implementarla?

Primero sería necesario calcular la tasa de No-Show para cada segmento utilizando los datos disponibles.

Después, se establecerían niveles de alerta y se agregarían indicadores de colores al dashboard mediante Streamlit.

Finalmente, se comprobaría que las alertas respondan correctamente a los filtros y que los resultados coincidan con los datos originales.

## Conclusión

Esta propuesta permitiría que el dashboard no solo mostrara información, sino que también ayudara a identificar situaciones importantes y facilitara la toma de decisiones.
